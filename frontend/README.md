# Frontend

Next.js web client for Gorilla.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Default Local URL

```text
http://localhost:3000
```

## Notes

- the frontend talks to the backend with session cookies
- browser speech recognition is used for speech input
- Azure Speech TTS audio is played from the backend response
- the Gorilla avatar scene lives in `src/components/gorilla-avatar-stage.tsx`
